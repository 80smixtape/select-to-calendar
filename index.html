How to use
  1. Install this page: in Chrome, open the menu and choose Install app.
  2. In any app, select text that mentions a date or time.
  3. Tap Share, then pick To Calendar.
  4. Check the event, then tap Add to Google Calendar and save it there.

Dates and times are read on this device. Only the finished event link is opened in Google Calendar.
